# Rego — 브릭 스튜디오

브라우저에서 동작하는 3D 브릭 조립 프로그램입니다. 실제 브릭 치수로 만든 부품을 스터드에 딸깍 끼워 조립하고, 구조가 버티는지 분석하고, 설명서를 따라 모델을 완성할 수 있습니다.

**바로 실행:** `docs/index.html` 하나에 모든 코드가 들어 있습니다. 파일을 브라우저로 열거나, GitHub Pages(Settings → Pages → `docs/` 폴더)로 배포하면 태블릿·휴대폰에서도 열립니다.

## 무엇을 할 수 있나

| 기능 | 내용 |
| --- | --- |
| 자유 조립 | 놓기 · 빼기 · 칠하기 · 집기, 회전, 실행 취소/다시 실행(200단계), 자동 저장 |
| 부품 66종 | 브릭, 플레이트(최대 16×16), 타일, 45°/65° 경사·코너·용마루·역경사, 원형·콘·돔, 아치, 창문, 문, 꽃, 안테나, 나무 |
| 색상 33종 | 실제 브릭 색상표 기반(불투명 · 투명 · 펄/메탈릭) |
| 조립 설명서 | 단계별 부품 목록, 반투명 자리 표시를 눌러 직접 끼우기, 자동 조립(1×–10×) 타임랩스 |
| 구조 분석 | 스캔 애니메이션, 약한 연결부 표시, 하중 히트맵, 받침이 빠지면 위 부품이 떨어짐 |
| 갤러리 | 구시가지 광장(639개), 성문과 해자, 바위섬 등대, 정원 오두막, 원형 기둥, 흔들리는 크레인 |
| 소리 | 합성한 결합음(2단 딸깍 + 몸체 공진 + 무게감), 빼는 소리, 떨어지는 소리, 생성형 배경 음악 |

## 조립 품질

- **실제 치수:** 8mm 피치, 브릭 높이 9.6mm, 플레이트 3.2mm, 스터드 Ø4.8×1.7mm, 이웃 부품 사이 0.1mm 간극과 모서리 라운드. 이음새가 실제 브릭처럼 보입니다.
- **스터드 결합 규칙:** 부품은 스터드가 하나 이상 맞물려야 놓입니다(위에 얹기, 아래에 매달기 모두 가능). 타일 위에는 붙지 않고, 겹치면 놓이지 않습니다.
- **엇갈려 쌓기:** 갤러리 모델의 벽은 이음새가 위아래로 겹치지 않도록 동적 계획법으로 브릭 길이를 고릅니다. 모든 모델은 테스트에서 저장된 순서대로 한 개씩 끼웠을 때 매번 연결되고, 약한 연결부가 0개임을 검증합니다(시연용 크레인 제외).
- **구조 분석:** 스터드 연결 그래프에서 하중을 바닥까지 흘려보내며 다음을 찾습니다.
  - 떠 있는 부품
  - 스터드 1개로만 이어진 유일 경로(돌아가 버리는 회전축)
  - 하중 중심이 지지 스터드 영역 밖으로 벗어난 돌출
  - 결합력을 넘는 매달림 하중

## 조작

| 동작 | 마우스 | 터치 |
| --- | --- | --- |
| 부품 놓기 | 클릭 | 한 번 눌러 자리 확인 → 같은 곳 다시 누르기 또는 **여기에 놓기** |
| 둘러보기 | 왼쪽 드래그 회전, 오른쪽 드래그 이동, 휠 확대 | 한 손가락 회전, 두 손가락 확대/이동 |

단축키: `B` 놓기 · `E` 빼기 · `P` 칠하기 · `I` 집기 · `R` 회전 · `Ctrl+Z`/`Ctrl+Shift+Z` · `F` 전체 보기 · `H` 히트맵 · `A` 구조 분석 · 설명서에서 `←`/`→`/`Space`

## 개발

```bash
npm install
npm run dev     # http://localhost:5173 (src 변경 시 다시 빌드)
npm run build   # docs/index.html, dist/artifact.html 생성
npm test        # 부품·결합·구조 분석·모델·소리 합성 테스트
```

| 파일 | 역할 |
| --- | --- |
| `src/pieces.js` | 부품 카탈로그(점유 칸, 스터드, 소켓, 형상 설명), 회전 |
| `src/world.js` | 격자 세계: 충돌, 스터드 맞물림, 연결 그래프, 낙하 |
| `src/structure.js` | 하중 흐름·브리지 탐색 기반 구조 분석 |
| `src/builder.js`, `src/models.js` | 엇갈려 쌓기 벽·지붕·첨탑 생성기와 갤러리 모델 |
| `src/geometry.js` | 부품 형상(라운드 모서리, 선반형 원형 부품, 경사, 아치, 창문) |
| `src/renderer.js` | three.js 렌더링: 인스턴싱, 가려진 스터드 제거, PBR, GTAO, 그림자 |
| `src/audio.js` | 효과음 합성과 생성형 음악 |
| `src/main.js` | 도구, 입력, 설명서, 갤러리, 분석 화면 |

three.js 외에 외부 음원·이미지 파일은 사용하지 않습니다.
